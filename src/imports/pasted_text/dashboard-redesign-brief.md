You are a Senior Product Designer and UX Strategist.

I have a financial research platform with the following sidebar modules:

- Dashboard
- AI Chat
- Watchlist
- Screener

Important:
The Dashboard is NOT the landing page. Users already know the platform and may navigate to Dashboard from other sections.

Current Issue:
The Dashboard currently shows only a list of companies. As a result, it feels like a data table rather than a useful dashboard. Users do not immediately understand what insights are important, what actions are available, or where they should go next.

Redesign the Dashboard to provide an excellent user experience while keeping it focused on decision-making and navigation.

Design Goals:

1. Transform Dashboard into an Insights Hub
Instead of simply displaying companies, surface meaningful information such as:
- Market overview
- Recently viewed companies
- Watchlist highlights
- Screener results summary
- AI-generated insights
- Trending stocks
- Portfolio/watchlist movements
- Important alerts

2. Improve User Orientation

When a user opens Dashboard, they should immediately understand:

- What is happening right now?
- Which companies deserve attention?
- What changed since their last visit?
- What actions can they take next?

3. Create Strong Navigation Paths

Dashboard should naturally guide users toward:
- AI Chat for deeper analysis
- Watchlist for monitoring stocks
- Screener for discovering opportunities

Add prominent action cards such as:
- Analyze with AI
- Open Watchlist
- Run a Screener
- View Company Details

4. Replace the Plain Company List

Convert company information into a more engaging experience:

- Company cards
- Trending companies section
- AI recommended stocks
- Recently viewed companies
- Top movers
- Sector leaders

Each company card should include:
- Company logo
- Company name
- Sector
- Key metrics
- Quick actions
- AI analysis shortcut

5. Add Dashboard Widgets

Possible widgets:

- Watchlist Snapshot
- Market Summary
- Screener Activity
- Recent Searches
- AI Insights
- Recent Company Analysis
- Alerts & Notifications
- Activity Timeline

6. Improve Visual Hierarchy

Users should instantly identify:

Primary:
- Important insights
- Alerts
- Recommended actions

Secondary:
- Recently viewed items
- Historical activity

Tertiary:
- Supplemental information

7. Premium SaaS Experience

Design should feel similar to:
- Bloomberg Terminal (simplified)
- TradingView
- Databricks
- Microsoft Fabric
- Stripe Dashboard

Use:
- Modern card layouts
- Clean whitespace
- Consistent spacing
- Professional typography
- Intelligent use of color
- Responsive design

8. Focus on Engagement

The Dashboard should encourage users to continue their workflow.

Example flow:

User sees a trending company →
Clicks Analyze →
Moves to AI Chat →
Gets insights →
Adds company to Watchlist →
Uses Screener to find similar opportunities

Design the Dashboard to naturally support this journey.

Deliverables:
- Redesigned Dashboard layout
- UX improvements
- Information architecture improvements
- New widgets and components
- Navigation recommendations
- Clear rationale for every change

Important:
Do NOT make the Dashboard a landing page. It should function as an intelligent workspace that helps users monitor information, discover opportunities, and quickly navigate to AI Chat, Watchlist, and Screener when needed.
